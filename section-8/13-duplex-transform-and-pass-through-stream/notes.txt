Duplex, Transform, Pass Through Streams

🟦 1. Duplex Stream

It can read and write data — both at the same time.
Think of it like a walkie-talkie — you can send and receive messages.

🟩 2. Transform Stream

It can read and write, but it also changes (transforms) the data in between.
Think of it like a translator — you say something, it converts it, and then passes it on.

🟨 3. PassThrough Stream

It also reads and writes, but it does not change the data.
Think of it like a glass pipe — data just passes through it.

-------

🔁 Duplex, Transform & PassThrough Streams in Node.js
These are advanced types of streams in Node.js used when you need more control over both reading and writing data — often useful in networking, compression, or real-time data processing.

Duplex Stream
What it is: A stream that can both read and write independently.
Analogy: Like a walkie-talkie — you can talk and listen at the same time, but they are separate actions.
Use case: Network sockets (net.Socket), where you receive and send data simultaneously.
From: import { Duplex } from "stream";

Transform Stream (Subclass of Duplex)
What it is: A special type of Duplex stream that modifies the data as it is written and before it’s read.
Analogy: Like a translator — input comes in one language, it gets converted, and output is in another.
Use case: Compression, encryption, converting data formats (e.g. CSV → JSON).
From: import { Transform } from "stream";

PassThrough Stream (Special Case of Transform)
What it is: A Transform stream that doesn't modify the data — just passes it through.
Analogy: Like a glass tube — the data goes in one end and comes out exactly the same.
Use case: Debugging, logging, monitoring traffic in a pipeline without altering the content.
From: import { PassThrough } from "stream";
