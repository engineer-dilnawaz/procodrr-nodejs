⚡ Why Streams Are Fast in Node.js
Streams offer significant performance advantages over traditional methods like appendFileSync or writeFileSync, especially when working with large datasets.

🔍 How Streams Work Internally
✅ A stream opens the file only once.
✅ It uses an internal buffer (in RAM) to load and manage data in small chunks.
✅ Data is written efficiently and continuously to the destination.
✅ Once writing is done, the stream closes the file.
➡️ This means: File open + multiple efficient writes + file close = super fast

🐢 Why appendFileSync / writeFileSync Are Slower
❌ Each appendFileSync or writeFileSync call:
Opens the file 📂
Writes data 💾 (directly to disk)
Closes the file 🚪
➡️ This happens every time inside a loop — leading to thousands of open/write/close operations!

Why Streams are fast ?
    
    Stream open file for the first time only and load all the data in internal buffer(RAM) and write all at once. After writing it close the file.

    But appendFileSync and writeFileSync open the file write the data(on DISK) and close it. Means it opens/close file for every write operation.
