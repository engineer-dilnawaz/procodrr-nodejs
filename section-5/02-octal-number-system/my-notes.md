## Octal Number System

- Octal numbers are -> 0,1,2,...,7
- Base 8
- In JS Octal numbers are represented by 0o123
  - Before ES6 only 0 was used in front of a number like 0123,
  - Now in ES6 we use 0 and o Note. O can be capital or small but convention is small o
  - we can use 0 without o with number to represent octal in today's JS if the JS has no 'use strict' mode or in package.json type is not module as module type already has 'use strict' enabled
