📁 FILE OPERATIONS – Node.js fs
1️⃣ fs.rename(oldPath, newPath)
✅ Why use

File ya folder ka naam change karne ke liye

File ko ek folder se dusre folder me move karne ke liye

📘 Definition

Existing file/folder ka path change karta hai (rename ya move).

🧪 Practical Example
import fs from "fs";

// rename file
fs.rename("data.txt", "info.txt", () => {
  console.log("File renamed");
});

// move file
fs.rename("info.txt", "./backup/info.txt", () => {
  console.log("File moved");
});

2️⃣ fs.copyFile(src, dest)
✅ Why use

Single file copy karne ke liye

📘 Definition

Source file ko destination me copy karta hai.

🧪 Practical Example
import fs from "fs";

fs.copyFile("data.txt", "data-copy.txt", () => {
  console.log("File copied");
});


🧠 Use case:
➡️ Backup file banana

3️⃣ fs.cp(src, dest, { recursive: true })
✅ Why use

Complete folder + subfolders + files copy karne ke liye

📘 Definition

Ek directory ko recursively copy karta hai.

🧪 Practical Example
import fs from "fs";

fs.cp("project", "project-backup", { recursive: true }, () => {
  console.log("Folder copied");
});


🧠 Use case:
➡️ Project backup / deployment

4️⃣ fs.unlink(path)
✅ Why use

Single file delete karne ke liye

📘 Definition

File ko permanently delete karta hai.

🧪 Practical Example
import fs from "fs";

fs.unlink("temp.txt", () => {
  console.log("File deleted");
});

5️⃣ fs.rmdir(path)
✅ Why use

Empty directory delete karne ke liye

📘 Definition

Sirf empty folder ko remove karta hai.

🧪 Practical Example
import fs from "fs";

fs.rmdir("empty-folder", () => {
  console.log("Directory removed");
});


⚠️ Folder empty hona chahiye

6️⃣ fs.rm(path, { recursive: true })
✅ Why use

Folder + andar ka sab kuch delete karne ke liye

📘 Definition

Directory ko recursively delete karta hai (files + subfolders).

🧪 Practical Example
import fs from "fs";

fs.rm("old-project", { recursive: true, force: true }, () => {
  console.log("Directory deleted completely");
});


🔥 Very powerful → carefully use karo

7️⃣ fs.mkdir(path)
✅ Why use

New directory create karne ke liye

📘 Definition

New folder create karta hai.

🧪 Practical Example
import fs from "fs";

fs.mkdir("uploads", () => {
  console.log("Folder created");
});


📌 Nested folder:

fs.mkdir("public/images", { recursive: true }, () => {});

8️⃣ fs.stat(path)
✅ Why use

File/folder ka size, type, created time check karne ke liye

📘 Definition

File ya directory ka metadata deta hai.

🧪 Practical Example
import fs from "fs";

fs.stat("data.txt", (err, stats) => {
  console.log("Size:", stats.size);
  console.log("Is File:", stats.isFile());
  console.log("Is Directory:", stats.isDirectory());
});


🧠 Use case:
➡️ Upload validation (file size check)

9️⃣ fs.watch(path)
✅ Why use

File/folder me changes detect karne ke liye

📘 Definition

File system ke changes ko real-time me watch karta hai.

🧪 Practical Example
import fs from "fs";

fs.watch("file-1.txt", (eventType, filename) => {
  console.log("Event:", eventType);
  console.log("File:", filename);
});

📌 Events

change → content changed

rename → file rename / delete

🧠 Use case:

Auto reload

Log monitoring

Live build tools (nodemon)

🧠 Summary Table

Some Methods for FILE OPERATIONS 

fs.rename(oldpath, newpath) -> Renames the file (Also used for moving)
fs.copyFile(src, des) -> copyFile from src to des
fs.cp(src, des, {recursive: true} ) -> copy whole folder from src to des
fs.unlink(path) -> Deletes the file
fs.rmdir(path) -> Deletes empty directory
fs.rm(path, {recustive: true}) -> Delete whole directory recursively.
fs.mkdir(path) -> crate a directory
fs.stat(path) -> give the stats of the file and folder
fs.watch(path) -> Watch a particular file and we csn monitor it. (use callback method avoid promises)
		  It has two events (Change and rename);
