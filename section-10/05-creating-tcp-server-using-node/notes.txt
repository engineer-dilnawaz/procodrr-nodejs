TCP Server

    const net = require('net');

    const server = net.createServer((socket) => {
        console.log("Client connected");

        // Server Info
        console.log(socket.address());

        // Client Info
        console.log(socket.remoteAddress);
        console.log(socket.remotePort);
        console.log(socket.remoteFamily);

        // Receiving data from client
        socket.on('data', (data) => {
            console.log("Client says:", data.toString());
            
            // Sending response back
            socket.write("Hello from server");
        });

        // Detect client disconnection
        socket.on('close', () => {
            console.log("Client disconnected");
        });
    });

    server.listen(3000, () => {
        console.log("Server listening on port 3000");
    });

    TCP 3-Way Handshake (Before Data Transfer)
        Client → Server: SYN
        Server → Client: SYN + ACK
        Client → Server: ACK
    Connection established. Ready to exchange data.

    socket.address()	    Shows server IP and port
    socket.remoteAddress	Shows client IP
    socket.remotePort	    Shows client port
    socket.remoteFamily	    Shows IP type (e.g., IPv4/IPv6)

    Duplex Stream (Bi-directional)
        socket is a duplex stream: you can both read from and write to it.
        Use socket.write() to send data back to client.

=========

TCP Server – Short Notes
🔎 Explanation
Creating Server
net.createServer()
TCP server create karta hai jo incoming connections handle karta hai.
Listening
server.listen(port, host, callback)
Server given port aur host par listen karta hai.
Callback tab run hota hai jab server successfully start ho jata hai.
Connection Event
server.on("connection", callback)
Har naye client ke liye callback run hota hai.
Is callback me socket milta hai jo us particular client ko represent karta hai.


🔁 Socket ka Role
socket ek duplex stream hota hai.
Isme read aur write dono possible hote hain  
  (bi-directional communication).
Data Read (Client → Server)
socket.on("data")
Client se aane wala data yaha read hota hai.
Data Buffer ke form me aata hai.
Data Write (Server → Client)
socket.write()
Server client ko response bhejta hai.
Connection End
socket.end()
Server signal deta hai ki response complete ho chuka hai
Client ko pata chal jata hai ki connection close hone wala hai.


🧾 Client Info
socket.remoteAddress → Client ka IP address
socket.remotePort → Client ka port number
socket.remoteFamily → IP version (IPv4 ya IPv6)


✅ Summary
Har client ke liye alag socket hota hai
Multiple clients parallel handle hote hain
read → write → end ek clean request–response flow banata hai
